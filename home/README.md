# Home Directory (~/)

This file explains what lives in the home directory, what's managed by
[dotfiles](https://github.com/nickmorozov/dotfiles), and why certain things
are or aren't tracked in version control.

Most dotfiles and dotdirs here are **symlinks** into `~/.dotfiles/home/`.
Dotbot creates them automatically when you run `~/.dotfiles/install`.

## Managed by Dotfiles (tracked in git)

### Shell
| Path | What it does |
|------|-------------|
| `.zshenv` | Environment vars, `$PATH`, helper functions. Loaded by every zsh instance |
| `.config/zsh/.zshrc` | Interactive shell config — plugins, completions, prompt |
| `.config/zsh/aliases.zsh` | Personal aliases (brew, python, yazi, config editing) |
| `.config/zsh/osx.zsh` | macOS helpers: dock management, app control, Launchpad |
| `.config/zsh/sf.zsh` | Salesforce CLI aliases and scratch org workflows |
| `.config/zsh/work.zsh` | Work/personal focus mode toggle (`dbw`, `dbp`, `dbt`) |
| `.inputrc` | Readline config (bash and some CLI tools) |
| `.hushlogin` | Suppresses "Last login" message in new terminals |
| `.crontab` | Cron job definitions. Load: `crontab ~/.crontab`. Save: `crontab-save` |
| `.aliases.zsh` | Legacy symlink → `.config/zsh/aliases.zsh` |

### Git
| Path | What it does |
|------|-------------|
| `.gitconfig` | Git config: 5 aliases (`l`, `ll`, `amend`, `undo`, `sync`), colors, diff. Includes `.gitlocal` |
| `.gitlocal` | Your name and email for git commits (machine-specific, not shared) |
| `.config/git/ignore` | Global gitignore (`.DS_Store`, Claude local settings) |

### Editors
| Path | What it does |
|------|-------------|
| `.config/nvim/` | Neovim config ([NvChad](https://nvchad.com/) fork, git submodule) |
| `.config/nvim/vimrc` | Traditional vim settings shared with IdeaVim |
| `.ideavimrc` | JetBrains IdeaVim config. Sources `~/.config/nvim/vimrc` |

### Dev Tools
| Path | What it does |
|------|-------------|
| `.Brewfile` | Homebrew bundle — all packages, casks, taps, Mac App Store apps |
| `.czrc` | Commitizen config (conventional commits) |
| `.config/gh/` | GitHub CLI config and auth tokens |
| `.sf/` | Salesforce CLI v2 config and caches |
| `.sfdx/` | Salesforce CLI auth orgs (tracked so you don't re-auth after a restore) |

### Applications
| Path | What it does |
|------|-------------|
| `.config/iterm2/` | iTerm2 preferences + [color schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) (submodule) |
| `.config/jetbrains/idea/` | IntelliJ IDEA settings, keymaps, file templates, color themes |
| `.config/raycast/` | Raycast config (extensions are NOT tracked — see below) |
| `.config/flipperdevices.com/` | Flipper Zero (qFlipper) settings |
| `.config/wireshark/` | Wireshark capture profiles |

### User Scripts & Tools
| Path | What it does |
|------|-------------|
| `.local/bin/` | Personal scripts (in `$PATH`) + symlinks to submodule tools |
| `.local/repos/focus-manager/` | macOS Focus mode CLI (git submodule) |
| `.local/repos/osx-calendar-syncer/` | Calendar sync tool (git submodule) |
| `.local/repos/sudo-askpass-security/` | Keychain-based sudo askpass (git submodule) |

### Claude Code
| Path | What it does |
|------|-------------|
| `.claude/settings.json` | Claude Code preferences |
| `.claude/plugins/` | Installed plugins and marketplace config |
| `.claude/projects/*/memory/` | Per-project memory files |

## NOT Managed / NOT Tracked

These exist in `~/` but are **not** in version control:

### Too large / auto-generated
| Path | Why not tracked |
|------|----------------|
| `.config/raycast/extensions/` | ~900 MB compiled JS, auto-updated by Raycast |
| `.local/bin/uv`, `.local/bin/uvx` | Python package manager binaries — reinstall via `brew` or `pip` |
| `.local/bin/lsp-*.jar` | Language server JAR — reinstalled by IDE |
| `.local/bin/claude` | Claude CLI binary — installed separately |
| `.local/bin/*.png` | App icons used by Shortcuts/Raycast |

### App caches and runtime state
| Path | Why not tracked |
|------|----------------|
| `.config/Autodesk/` | Auto-generated by Fusion 360 |
| `.config/swiftpm/` | Swift Package Manager cache |
| `.config/jgit/` | JGit cache |
| `.config/neovide/` | Neovide GUI settings (using terminal nvim instead) |
| `.config/.android/` | Android SDK config |
| `.claude/` session data | Backups, image cache, paste cache, plans, telemetry — all transient |

### macOS system directories (not part of dotfiles)
| Path | What it is |
|------|-----------|
| `Library/` | macOS app data, preferences, caches |
| `Applications/` | User-installed apps (Homebrew casks go to `/Applications`) |
| `Desktop/`, `Documents/`, `Pictures/`, `Movies/`, `Music/` | Standard macOS user folders |
| `Downloads/` | Symlink → iCloud Downloads (created by `~/.dotfiles/scripts/downloads`) |
| `Projects/` | Code projects (Repos, Forks, Job, Playground) |
| `.ssh` | Symlink → iCloud SSH keys (created by `~/.dotfiles/scripts/services`) |
| `.cache/`, `.npm/`, `.cargo/`, `.nuget/` | Package manager caches |
